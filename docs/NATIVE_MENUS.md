# Native main and Esc menu styling

Project Version: 0.5.0-dev.6

Compatible MINOR integration within public Lua API 1. Development source only; no deployment, package or upload for this iteration. Workshop item 3822582242 remains at the recorded 0.3.0-dev.1 build.

When the UI mod's client Lua loads, NativeMenus requires OptionScreens/MainScreen, then registers after its native construction callbacks for OnMainMenuEnter and OnGameStart. OnResetLua and an immediate pass cover an existing instance. Both the front-end and in-game Esc menu use MainScreen. There is no per-frame discovery or global class override.

The adapter changes only the prerender of recognized direct bottomPanel navigation labels: Continue, Load, Tutorial, Solo/demo, Multiplayer, Host, Return, Scoreboard, Invite, Options, Mods, Workshop, Credits, Exit and Quit to Desktop when present. It retains native localized names/internal IDs, mouse callbacks, controller rows/default focus, visibility and geometry. Missing or hidden actions stay missing or hidden. Debug/report/TOS/version controls and application-screen buttons remain outside the adapter.

The native Large font and existing font-aware row height are preserved. Idle text uses the shared foreground token. Hover/controller focus uses the accent and the same 2px label-only underline as MenuButton; the old grey hover rectangle is omitted. Native fade state/audio, controller A glyph and tooltip drawing remain. Fitted display text is temporary; full names/translations remain available to native code and a fallback tooltip preserves truncated text. Existing tooltips take precedence. Width changes are evaluated at draw time. Delay/tutorial/save-modal and quit-cooldown guards suppress the active visual, while all input/action guards stay with vanilla.

Appearance reads the existing B47ANCEDUI scope at local slot 0, default grey #B0B0B0. It does not borrow Quartermaster's appearance. The public scoped Appearance/AppearanceEditor APIs can edit that profile; this slice adds no new menu entry or preference format. There is no shared gameplay configuration, server state, custom synchronization or persistence migration. All constants/allowlists are internal drawing and compatibility constraints, so no server sandbox option is appropriate.

Ownership checks require native label type, known field/internal ID, direct parent, Large font, matching native callback/prerender and transition. Already styled/foreign controls are skipped. Other mods that replace the same MainScreen entrypoints or run after the adapter may still conflict; their source is not modified and compatibility is NOT TESTED. No complete menu redesign, CCTV, font replacement, pause behavior or quit/load implementation is added.
